# 3. Preparar a los participantes

**Objetivo:** dejar al participante con los marcadores bien puestos y el esqueleto creado y refinado.

## Pasos
1. Pon el traje de captura al participante.
2. Coloca los marcadores según el set de tracking **Conventional 39**, para obtener el movimiento corporal.
   ![Colocación de marcadores](img/03_marcadores.png)
3. Comprueba que los marcadores sean visibles para varias cámaras.
4. Ubica al participante frente a la cámara 3, en **pose T**, y crea el esqueleto.
   ![Pose T](img/03_pose_t.png)
5. Para refinar el esqueleto, pide al participante una serie de movimientos (por ejemplo: subir las manos al cielo, juntar los codos, mover los pies), para que el sistema identifique bien las partes del cuerpo.

## ✅ Cómo saber que quedó bien
- Marcadores visibles para varias cámaras.
- Esqueleto creado e identificando bien las partes del cuerpo.

## ⚠️ Punto crítico
El refinamiento del esqueleto es lo que hace que las capturas sean limpias y fluidas. No lo omitas.

## 🛠️ Si algo falla
| Síntoma | Qué hacer |
|---|---|
| El sistema no identifica bien alguna parte del cuerpo | Repite los movimientos de refinamiento |
| Marcadores no visibles para varias cámaras | [completar] |
